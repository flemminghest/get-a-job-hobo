# Get a Job Hobo — gratis webdemo

Statisk, responsiv webapp på dansk. Ingen betaling, server, installation eller API-nøgle er nødvendig for de lokale demo-funktioner.

## Funktioner
- Jobanalyse på lokal, regelbaseret heuristik.
- CV-redigering og lokal lagring i browseren.
- Tre ansøgningsforslag efter analyse; ansøgningsfeltet starter blankt og udfyldes først efter aktivt valg.
- Panelkritik for Recruiter, Copywriter, CMO og CEO (demo-feedback).
- Import af LinkedIn Connections.csv og valgfri SavedJobs.csv, søgning, filtre og eksport.
- Manuel registrering af kilder, dubletkontrol, domæneoptælling og synlig foreløbig researchstatus.
- Historik, backup/restore og sletning af lokale data.

## Vigtigt
- Denne app indeholder ikke private CV-/LinkedIn-data; importer selv dine data i browseren.
- CV og CSV-filer behandles lokalt og sendes ikke til en backend.
- AI, live-webresearch, PDF/OCR, sikker login/backend, enhedssynkronisering og direkte LinkedIn API er ikke tilkoblet.
- Scores og panelkritik er regelbaseret demo-logik; ikke statistiske vurderinger.
- Brug backup, og hold den privat.

## GitHub Pages
Workflow i `.github/workflows/pages.yml` publicerer `index.html` fra standardbranchen via GitHub Actions. Under repository Settings → Pages skal source stå på GitHub Actions, hvis GitHub ikke allerede har valgt det.
